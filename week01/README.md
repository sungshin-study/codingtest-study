각 문제 폴더(`01-섬연결하기` 등) 안에 `이름.py`(또는 `이름.java`) 파일 하나만 올려주세요. 설명은 별도 파일 없이 코드 상단 주석(docstring/KDoc)에 씁니다.

```

├── 이름1.py
└── 이름2.java
```
