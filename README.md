# codingtest-study

코딩테스트 스터디 레포지토리입니다. 주차별로 문제를 정해서 각자 풀고, 풀이 코드와 설명을 올립니다.

## 진행 방식

- 매주 폴더(`week01`, `week02`, ...)를 만들고 그 안에 문제별 폴더를 둡니다.
- 각자 자기 언어(Java, Python 등)로 풀어서 **문제 폴더 안에 `이름.py`(또는 `이름.java`) 파일 하나**만 올립니다. 별도 설명 파일 없이, 풀이 설명은 코드 상단 주석(Python docstring / Java KDoc·Javadoc 스타일)으로 씁니다.
- 브랜치/PR 없이 **`main`에 바로 push**합니다. 사람마다 건드리는 파일이 겹치지 않아 충돌 위험이 거의 없기 때문입니다. (원한다면 개인적으로 브랜치를 써도 되지만, 머지 시 리뷰를 기다릴 필요는 없습니다.)
- 커밋 메시지는 `[이름] 주차/문제명 풀이` 형식을 권장합니다. 예: `[지원] week01/섬연결하기 풀이`

## 폴더 구조

```
week01/
├── README.md                # 이번 주 문제 목록 + 링크
├── 01-섬연결하기/
│   ├── 이름1.py
│   └── 이름2.java
├── 02-입국심사/
├── 03-징검다리/
├── 04-타겟넘버/
└── 05-더맵게/
```

새 문제를 풀 때는 `_template/Template.py` 또는 `_template/Template.java`를 복사해서 `이름.py`/`이름.java`로 이름 바꾸고 채우면 됩니다. 설명은 파일 상단 주석에 씁니다.

## 참고사항 (Mac 사용자)

macOS는 한글 파일/폴더명을 NFD로 저장해서 GitHub 등에서 자모가 분리되어 보이는 경우가 있습니다. 아래 설정을 한 번 해두면 방지할 수 있습니다.

```
git config --global core.precomposeunicode true
```
