## 제출 방법

각 문제 폴더(`01-N으로표현` 등) 안에 `이름.py`(또는 `이름.java`) 파일 하나만 올려주세요. 설명은 별도 파일 없이 코드 상단 주석(docstring/KDoc)에 씁니다.

```
week02/01-N으로표현/
├── 이름1.py
└── 이름2.java
```

루트의 `_template/Template.py` 또는 `_template/Template.java`를 복사해서 이름만 바꿔 쓰면 됩니다.
